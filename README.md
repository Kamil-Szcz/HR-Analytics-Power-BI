# HR Analytics Dashboard - PixelAI Studio

Power BI project based on HR data from a fictional company - **PixelAI Studio**.

The project covers the complete data analysis workflow, from data cleaning and transformation to data modelling, DAX calculations and interactive dashboard development.

## Project Objective

The main objective was to analyse the company's workforce structure and employee turnover, with a focus on:

- Headcount and FTE trends
- Employee resignations
- Turnover ratio
- Workforce structure by age and gender
- Employment type
- Departments, teams and supervisors with the highest number of resignations
- Changes in workforce size over time

## Tools & Technologies

- **Power BI**
- **Power Query** - data cleaning and transformation
- **DAX** - measures and KPI calculations
- **Data Modelling** - relationships and analytical structure
- **Excel** - source data

## Project Workflow

### 1. Data Cleaning & Transformation

Raw HR data was prepared in Power Query. The process included:

- correcting data types,
- cleaning and standardising values,
- handling missing and inconsistent data,
- transforming date-related fields,
- preparing the data for analysis.

### 2. Data Modelling & DAX

A Power BI data model was created to support analysis of employees, departments, teams, contracts and resignations.

DAX measures were created for key metrics including:

- Headcount
- FTE
- Number of Resignations
- Turnover Ratio
- Average Headcount
- Turnover Ratio for the analysed period

### 3. Dashboard

The final report consists of three interactive sections:

**Monthly Report**  
Provides an overview of current workforce levels and monthly trends.

**Decomposition Tree**  
Allows resignations to be analysed across organisational levels such as department, team and supervisor.

**Quarterly Report**  
Provides a longer-term view of headcount, turnover and employment structure.

## Key Insights

The dashboard makes it possible to identify:

- periods with increased employee turnover,
- departments and teams with the highest number of resignations,
- changes in headcount over time,
- workforce distribution across age groups and genders,
- differences in employment structure,
- supervisors associated with a higher number of resignations.
